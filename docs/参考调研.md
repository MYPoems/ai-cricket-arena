## 改进清单（按收益排序）

### 第一批：小而实（✅ 2026-11-23 已实现）
1. 斗地主「提示」排序修正：按主牌点数而不是最小那张排，尽量不拆对子、三张；领出按单 → 对 → 连对 → 顺子 → 飞机 → 三带 → 炸弹 → 王炸。（S，**原来有 bug**）
2. 斗地主「点一下补全」：一张没选时点一张牌，自动选上包含它的最小一手合法牌。（M）
3. 斗地主记牌器：15 列（大王 … 3），显示每个点数还剩几张；剩 4 张的标金（可能有炸）。（S）
4. 牌桌思考计时：行动者名牌上显示「思考 12s」，越久颜色越热。（S）
5. 德扑真人快捷键：F 弃牌、C/空格 跟注或过牌、R 加注、A 全下，1/2/3 选加注预设；按钮上标按键。（S）
6. 回放键盘：← → 单步，Home / End 头尾，空格播放暂停，F 翻转。（S）
7. 狼人杀天亮死讯卡：天亮先弹「昨夜 X 号出局 / 平安夜」；白天放逐、猎人开枪，谁是卧底投出人时也弹，服务端停 2.6 秒等卡片演完。（S）

### 第二批：观战体验（M）
8. 狼人杀票型落到座位上：投票者到目标画弧线，揭晓时一票一票亮，被投座位挂得票数。
9. 德扑摊牌分步亮牌：按顺序一家家翻，牌型徽章弹出，输家牌变淡；大底池全下时转牌、河牌前多停 1 秒。
10. 德扑主池、边池依次推给各自赢家；底池收注时鼓一下。
11. 棋类评估曲线标失误点（大漏着红、失误橙、缓着蓝），加「关键时刻」导航（|ΔE| > 10%）。
12. 棋类准确率 %（lichess 公式），放进选手卡。
13. 斗地主各座位前显示最近一手（缩小），一眼看出谁不出。
14. 斗地主底牌交接动画、飞机 / 王炸 / 春天特效。
15. 走子动画时长跟回放倍速：clamp(0.6 × 每步间隔, 120, 440) ms。

### 第三批：平台与数据（M–L）
16. 天梯显示不确定性（μ ± σ），不对称游戏按角色分开算分（当狼 / 当民、地主 / 农民）。
17. 每个游戏的对位热力图，点格子看这两个模型的对局。
18. 德扑整场统计：累计盈亏曲线，入池率 VPIP、加注率 PFR、3-Bet、C-Bet。
19. 回放可用 URL 参数控制（turn、autoplay、speed），提供可嵌入页面。
20. 推理面板三档：原文 → 精简 → 一句话摘要。
21. 狼人杀观战视角切换：上帝 / 好人 / 附身某玩家；投票意向、怀疑度曲线。
22. 每局自动战报卡、每日精选。
23. 着法分级阈值：大漏着从 20% 改到 15%（和 lichess 一致），补「做出杀 / 丢了杀」的定级；妙手、唯一着需要引擎开 MultiPV 2。改了会让新旧对局的统计口径不一致，**先问本人再改**。
24. 音效（默认静音）、真人轮到时震动和后台标签页提醒。
25. 德扑预选操作、防误点、按大盲数显示。
