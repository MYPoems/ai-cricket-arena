## 改进清单（按收益排序）

### 第一批：小而实（✅ 2026-11-23 已实现）
1. 斗地主「提示」排序修正：按主牌点数而不是最小那张排，尽量不拆对子、三张；领出按单 → 对 → 连对 → 顺子 → 飞机 → 三带 → 炸弹 → 王炸。（S，**原来有 bug**）
2. 斗地主「点一下补全」：一张没选时点一张牌，自动选上包含它的最小一手合法牌。（M）
3. 斗地主记牌器：15 列（大王 … 3），显示每个点数还剩几张；剩 4 张的标金（可能有炸）。（S）
4. 牌桌思考计时：行动者名牌上显示「思考 12s」，越久颜色越热。（S）
5. 德扑真人快捷键：F 弃牌、C/空格 跟注或过牌、R 加注、A 全下，1/2/3 选加注预设；按钮上标按键。（S）
6. 回放键盘：← → 单步，Home / End 头尾，空格播放暂停，F 翻转。（S）
7. 狼人杀天亮死讯卡：天亮先弹「昨夜 X 号出局 / 平安夜」；白天放逐、猎人开枪，谁是卧底投出人时也弹，服务端停 2.6 秒等卡片演完。（S）

### 第二批：观战体验（M）
8. ✅ 狼人杀、谁是卧底票型弧线：投票中（上帝视角）金色虚线流动；揭晓时一票一票画出，投给出局者的朱红、其余淡金，6 秒后淡去。
9. ✅ 德扑摊牌分步亮牌：按顺序一家家翻，牌型徽章弹出，输家牌变淡；大底池全下时转牌、河牌前多停 1 秒。
10. ✅ 德扑主池、边池依次推给各自赢家；底池收注时鼓一下。
11. ✅ 棋类评估曲线标失误点（可点），「关键时刻」导航（J / K 键），终局自动弹战报（准确率、失误分布、三个关键时刻）。
12. ✅ 棋类准确率 %（lichess 公式），放进选手卡。
13. ✅ 斗地主各座位前显示最近一手（缩小），一眼看出谁不出；出牌主体在前、带牌在后。
14. ✅ 斗地主底牌交接动画、飞机 / 王炸 / 春天 / 顺子特效，结算卡写明倍数算式和每家得失，真人 30 秒提醒圈。
15. ✅ 棋类快速回放时，走子动画按倍速加快（playbackRate）。

### 第三批：平台与数据（M–L）
16. ✅ 天梯显示不确定性（估计实力 ± 误差），不对称游戏分阵营胜率和阵营分；新增均步时、Token/局、犯规率，活跃度筛选。
17. ✅ 每个游戏的对位热力图，点格子看这两人的对局。
18. ✅ 德扑整场统计：累计盈亏曲线、入池率 VPIP、加注率 PFR、摊牌、最大底池（3-Bet、C-Bet 暂不做）。
19. ✅ 链接参数 ?turn= / ?autoplay=1 / ?speed= / ?embed=1，转播条「复制这一步的链接」。
20. 推理面板三档：原文 → 精简 → 一句话摘要。
21. ✅ 观战「不剧透」视角（狼人杀、谁是卧底、斗地主、德扑都能用，服务端只给公共信息）。附身某玩家、投票意向和怀疑度曲线需要模型额外输出，暂不做。
22. 每局自动战报卡、每日精选。
23. ✅ 大漏着阈值从 20% 改为 15%（和 lichess 一致；本人允许 agent 改更好的方案）。旧对局保留当时的定级。妙手、唯一着需要引擎开 MultiPV 2，暂不做。
24. ✅ 音效（Web Audio 现场合成，默认关，转播条开关）、轮到真人时震动、后台标签页闪「轮到你」。
25. ✅ 德扑预选操作、防误点（跟注锁 1 秒、大额二次确认）、按大盲数显示。
