# 拆解：吹牛出牌 + 俄罗斯轮盘（「吹牛左轮」，id `liar`）

> 只借用公开、通用的玩法机制：经典纸牌游戏「吹牛 / Cheat / I Doubt It」出暗牌、声称点数、下家质疑翻牌，加上输家对自己扣左轮扳机的惩罚。
> 不使用任何商业产品的名字、角色、美术、音乐和场景外观；画面用本站自己的深红漆面 + 金边风格。

## 看了哪些公开资料

- Pagat「Cheat / Bullshit / I Doubt It」、维基百科 Cheat 词条：经典吹牛的规则和变体。
- 一份玩家整理的 Liar's Deck 完整规则说明（debigare.com）、ludo.guide 的规则页、Steam 商店页和几篇评测：只看规则和节奏。
- 开源项目 LYiHub/liars-bar-llm（让大模型玩这类游戏的框架）的说明：提示词拆成「出牌」「质疑」两类，模型输出格式不稳定时要重试。
- NeurIPS 2025 论文《Social Behaviour and Strategic Adaptation of LLMs in Multiplayer Sequential Games》、「Bluff and Learn」（CFR / NFSP 训练这类游戏的 AI）：只看摘要，确认这类游戏常被用来比较模型的诈唬和识谎。

## 经典「吹牛」的骨架（Cheat 家族）

- 轮流把牌扣着出到中间一堆，嘴上报点数，可以说谎。
- 任何人可以喊「我不信」：翻开刚出的那一手，有一张不符，出牌的人收走整堆；全符合，质疑的人收走。
- 「I Doubt It / Bluff」变体：所有人报同一个点数，直到有人质疑。
- 目标是先出完牌；最后一手也可以被质疑，被抓就把牌堆收回去。

## 加上左轮之后的变化（Liar's Deck 一类的公开规则）

- 牌组小而固定：Q、K、A 各 6 张 + 2 张鬼牌（万能），共 20 张；2–4 人。
- 每轮重新洗牌、每人发 5 张，翻出一张「桌牌」（Q/K/A 之一）：桌牌和鬼牌算真，其余是假。
- 轮到的人二选一：出 1–3 张暗牌声称都是桌牌，或者质疑上一手（每轮第一手不能质疑）。只有下家能质疑，只能质疑最近的一手。
- 质疑翻开上一手：有一张假，出牌的人输；全真，质疑的人输。
- 惩罚不再是收牌，而是输家对自己扣一次左轮：6 个弹巢 1 发子弹，整局不重转，扣得越多下一枪越危险（第 6 枪必中）。中弹出局。
- 手里没牌的人本轮跳过（不算出局）；只剩一个人有牌时，他必须质疑上一手。
- 一次质疑就结束这一轮：重新洗牌发牌、翻新桌牌。下一轮由被抓的说谎者先出，否则由下一个人先出。
- 最后活着的人赢。

## 节奏

- 一轮很短：4 人局一轮往往 3–8 手就有人质疑。出牌本身几乎没有操作，紧张感全在「信不信」和「扣扳机」上。
- 每次质疑都是一个小高潮；一局 2–4 人大约 5–12 次质疑。我们的内置 AI 自对弈平均每局约 30 手、8 次质疑。
- 原版每手限时 30 秒，逼人快速决定；我们沿用框架的真人限时，模型不限时。

## 成熟产品让人紧张的交互做法

1. **暗牌叠放**：牌扣着滑进中间，牌堆一层层变高；大家只看得到「几张」，看不到是什么。
2. **翻牌揭晓**：喊质疑后先停一拍，再把那一手一张张翻开，假牌一出现就定了输赢。
3. **扣扳机的停顿**：输家举枪、转轮、停顿好一会儿才扣下；「咔哒」（空膛）和「砰」（出局）的音效、镜头震动反差很大。
4. **每人的左轮状态公开**：谁已经扣了几次一目了然——这直接改变所有人的胆量（快没命的人不敢质疑，别人就敢对他诈唬）。
5. **全程能看到对手的反应**：语音、表情。我们的对应物是模型的中文思考（结束后公开）。

## 我们采用的规则

- 牌组、发牌、桌牌、出 1–3 张、只能质疑上一手、判定、6 弹巢 1 子弹不重转、没牌跳过、只剩一人有牌必须质疑：全部照公开规则。
- 子弹位置开局按种子定好（每把枪 1–6 中的一格），整局不变；任何视角（含上帝视角）都不给子弹位置，只给已扣几次。
- 下一轮由输家先出；输家出局则由他的下家先出。名次：活到最后第 1，其余按出局先后倒排。
- 行动 id：出牌是牌面按 Q K A 鬼 排序、空格分隔（`Q Q 鬼`），质疑是 `call`。鬼牌在提示词和界面上都叫「鬼」，解析时也认 J / Joker / 王。

## 简化和取舍（理由）

- **只做基础模式**：不做魔鬼牌、混沌牌、开枪打别人等变体——先把最核心的诈唬和识谎做扎实，提示词也短。
- **下一轮先手统一为输家**：公开资料里「质疑者输时由下一个人先出」说法含糊，统一成输家（出局则下家），规则一句话说得清。
- **出牌按座位号顺序**（1→2→3→4），不讲顺时针逆时针。
- **不会出现谁都没牌**：按「只剩一人有牌必须质疑」，最后一个出完牌的人之后总有人质疑，代码里只留防御分支。
- **出牌是私密步**：行动 id 就是真实牌面，所以有真人或自带 agent 在局时，出牌这一步不进公共事件流（`secret` 返回真），记录里只给本人；行动描述（label）只写「出 2 张，称都是 Q」，不带牌面。质疑是公开的。
- **质疑的描述不带结果**：「质疑 1 号位」，扣扳机的结果交给画面揭晓；本局记录里最近一次质疑的结果也要等下一手出现才写进去，避免扳机还没扣就剧透。
- **不做出牌倒计时**：沿用框架的真人限时（超时由系统按内置 AI 最低档代打；它在只能质疑时会质疑）。

## 揭晓的时刻表（服务端停顿 = 画面演出）

`games/liar/index.js` 导出 `T` 和 `revealPlan(n, dead)`，服务端 `interlude` 和画面、回放用同一份：

| 段落 | 时长 |
|---|---|
| 「质疑！」横幅 | 0.9 秒 |
| 翻开上一手（每张间隔 0.3 秒，翻一张 0.48 秒） | 约 0.6–1.3 秒 |
| 判定印章（说谎！/ 是真的，假牌描红） | 1.4 秒 |
| 桌面压暗，输家的弹巢放大、转几圈、心跳鼓动 | 2 秒 |
| 扣扳机：咔哒 / 砰！（中弹多停 0.8 秒，闪红、震屏） | 1.7 秒 |
| 新一轮：翻开桌牌，写明谁先出 | 2 秒 |

一次质疑总共停 8–10 秒；普通出牌之后停 1.3 秒（`turnPause`）。名牌上的小弹巢、出局状态都在扣扳机那一刻才更新。

## 给模型的提示词（省 token）

- 系统提示：6 行规则 + 五行输出格式（判断 / 推断 / 理由 / 胜率 / 最后一行「行动：出牌 Q Q」或「行动：质疑」）。
- 每步提示：轮次和桌牌、自己的手牌、本轮自己已出的牌、上一手（谁、几张）、牌堆张数、其他人手牌数 + 左轮已扣几次（下一枪概率）、出局者、最近 6 次质疑的结果；只能质疑时明说。
- 解析宽松：全角冒号、「两张 Q」「Q×2」「QQ」、J / Joker / 鬼牌，括号里的补充说明不算；错误理由具体（手里没有哪张、超过 3 张、本轮先手不能质疑、只能质疑）。

## 内置 AI

- **level 1**：随机合法（能质疑时 30% 质疑）。
- **level 2**：按超几何分布估算「对方手里凑得出这么多张真牌」的概率，说谎概率 ≥ 50% 就质疑；看得见的真牌已经不够时一定质疑。不质疑就诚实出全部真牌（最多 3 张），没有真牌只说谎出 1 张。
- **level 3**：在 level 2 上记住自己本轮出过的牌、按别人前几手大概用掉的真牌折算；手里有真牌时要很有把握才质疑（放过他代价小），只剩假牌时门槛放低；自己左轮越危险越不敢赌，对方越危险越想让他扣；下家左轮危险（不太敢质疑）时适当诈唬——真牌里混一张假牌，或者多甩一张假牌。
- 自对弈：level 3 对 level 2 单座胜率约 0.49 : 0.18，对 level 1 约 0.58 : 0.09。

## 画面要点（`web/stage/liar.js`）

- 深红漆面椭圆桌 + 金边，玩家本人在正下方；桌心左边牌匾翻着本轮桌牌，右边暗牌堆越叠越高，堆下挂上一手的声称（上帝视角另标真实牌面，假牌标红）。
- 每块名牌右侧嵌 6 格弹巢：黄铜是没扣过的格，空膛是扣过的，下一枪那格转到正上方，中弹那格变红；出局的名牌变灰盖「出局」章。
- 真人：点选 1–3 张手牌（选中的抬起），「出 N 张 · 称 Q」；能质疑时有红色「质疑 X 号」。
- 音效沿用站内合成音：翻牌「card」、空膛「chip」、中弹「bomb」+「out」（音效开关在转播条上）。
