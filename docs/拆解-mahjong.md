# 拆解：四川麻将 · 血战到底

只看公开资料：腾讯欢乐麻将血战模式的玩家整理（头条、B 站专栏、萌娘百科「四川麻将」词条的搜索摘要）、小米游戏中心单机版的计分说明、
RLCard（arXiv 1910.04376）的麻将环境、Mjai 协议的事件划分、天凤 / 雀魂的公开截图与交互习惯。商业产品只学思路，不照搬外观。

各平台的番数差异很大（同一个「对对胡」，有的写 1 番 / 2 倍，有的写 3 分；花猪有的赔 16 分，有的赔 6 倍），
所以我们挑了最常见的「番 = 2 的次方倍」体系，下面写清楚每一条，并在系统提示词里原样告诉模型。

## 一、规则要点

| 项目 | 主流做法 | 我们 |
|---|---|---|
| 牌 | 108 张：万、条、筒各 1–9 各四张，没有字牌、花牌 | 同 |
| 人数 | 4 人，每人 13 张，庄家 14 张先出 | 同 |
| 吃碰杠 | 不能吃；能碰、明杠（直杠）、暗杠、补杠（加杠 / 巴杠） | 同 |
| 换三张 | 欢乐麻将默认开：每人拿出同花色三张，按骰子顺 / 逆 / 对家交换 | **不做**（见第四节） |
| 定缺 | 开局四家同时选一门「缺」；有缺门牌时只能先打缺门，缺门的牌不能碰杠胡 | 同；四家同时行动，全定完再一起亮出 |
| 胡牌 | 4 面子 + 1 将，或七对（四张相同算两对）；手里不能有缺门 | 同 |
| 血战到底 | 一家胡了不结束，其余继续；三家胡了或牌墙摸完才结束 | 同 |
| 一炮多响 | 允许，打出的人分别赔每一家 | 同 |
| 下一盘庄家 | 欢乐麻将：先胡的人坐庄；一炮多响时放炮者坐庄 | **固定轮转**（每人坐庄次数一样，AI 对战更公平） |
| 过水不胡 | 部分规则：放过一张能胡的牌，到自己下次摸牌前不能再胡别人的牌 | 不做 |

## 二、流程

1. 发牌：带种子洗牌（mulberry32 状态存在 state 里），从庄家开始每人 13 张，庄家多摸一张。
2. 定缺：四家同时选。玩家视角里别人的选择先藏着（记录显示「已定缺」），全定完一起亮出。
3. 轮到某家：已经摸了牌，可以 **自摸**、**暗杠**、**补杠** 或 **打一张**（有缺门时只能打缺门）。
4. 打出一张后，只有 **能胡 / 能碰 / 能杠** 的人进入响应窗口（同时决定，可以过）；没人能响应就直接下一家摸牌，不空等。
   结算顺序：有人胡就胡（可以几家同时胡），否则杠，否则碰；碰后直接打牌，杠后补摸一张。
5. 补杠时如果别家能胡这张，先问他们（抢杠胡）；被抢了，补杠不成立、这张算被胡走。
6. 胡了的人退出这一盘：手牌在玩家视角里扣着，只亮胡的那张。从最后一个胡的人的下家接着摸牌。
7. 结束：只剩一家没胡，或者轮到摸牌时牌墙空了。流局（两家以上没胡）先查花猪，再查大叫，最后退税。
8. 一场打 `setup.hands` 盘（默认 4，1–16），庄家轮转，按累计分排名；`setup.cap` 设封顶番数（默认 4，2–6）。

## 三、计分

得分 = 2^番（封顶后）。点炮由打出的人付；自摸由每家没胡的付，并且每家多付 1（**自摸加底**，欢乐麻将是加番，这里选加底，免得自摸三家赔、再翻一倍太猛）。

| 番型 | 番 | 说明 |
|---|---|---|
| 平胡 | 0 | 1 分 |
| 对对胡 | 1 | 全是刻子 + 将 |
| 清一色 | 2 | 只有一门（清对 3、清七对 4、清龙七对 5 都由叠加得到） |
| 七对 | 2 | 四张相同算两对 |
| 龙七对 | 七对 2 + 根 | 每有一个四张就 +1 |
| 带幺九 | 2 | 每组面子和将都带 1 或 9 |
| 将对 | 对对胡 + 2 | 所有牌都是 2、5、8 |
| 金钩钓 | 对对胡 + 1 | 四组副露、单钓将 |
| 根 | 每个 +1 | 四张相同（含杠、碰后手里有第四张） |
| 杠上花 / 杠上炮 / 抢杠胡 / 海底捞月 / 海底炮 | 各 +1 | |
| 天胡 / 地胡 | 直接封顶 | 庄家起手胡 / 闲家第一次摸牌自摸，之前没人碰杠 |

刮风下雨（杠分，当场结算）：明杠放杠的人付 2；补杠每家没胡的付 1；暗杠每家没胡的付 2。

流局：
- **查花猪**：手里仍有缺门（三门都在）的人，赔每家「不是花猪、没胡」的玩家封顶分（默认 2^4 = 16）。
- **查大叫**：没听牌的人，赔每家听牌的人「他可能胡的最大番」。
- **退税**：没听牌（含花猪）的人退回这一盘收的杠分。

全局零和，测试里检查每场合计为 0。

## 四、采用和简化

- **不做换三张**：同时选三张的组合很多（每门 C(n,3)），模型要多一轮高 token 决策；四家同时换牌也让回放和隐藏信息复杂。以后可以作为 `setup.swap` 加回来（规则版本 `newSetup.rules`）。
- **庄家固定轮转**，不按「先胡坐庄」：AI 对战要比较实力，坐庄次数一样更公平。
- **不做过水不胡、呼叫转移（杠上炮转杠分）**：都是地方规则差异大的细则，对 AI 决策影响小。
- **自摸加底**而不是加番，理由见上。
- **胡了的人手牌扣着**（上帝视角能看）：和主流产品一致，也避免泄露剩余牌信息。
- **暗杠扣着**：别家看不到暗杠是什么牌（两头扣、中间两张明——上帝视角）。
- 牌墙顺序不进任何视角（观众也只有剩余张数）。

## 五、成熟产品的交互与观战做法（学思路）

- **桌面**：四家围坐，自己在下方；出牌顺序下 → 右 → 上 → 左（逆时针）。左右两家的牌横着摆。
- **牌河**：每家打出的牌按顺序在自己面前排成六张一行，从桌心往自己那边长；最新一张有箭头 / 高亮；被碰杠走的牌从牌河拿走。
- **桌心控制台**：剩余张数（快摸完时变红）、第几盘、指向当前出牌人的光。
- **定缺**：三个按钮，系统推荐张数最少的一门；定完在头像旁亮出缺门徽章（万红、条绿、筒蓝）。
- **听牌提示**：轮到自己时，打了能听牌的牌上挂「听」，选中时说明听什么、外面还剩几张；没轮到时显示自己在听什么。
- **响应**：别人打出牌时只有能响应的人弹出「胡 / 杠 / 碰 / 过」，其他人看到「等待响应」。
- **喊字**：碰、杠、胡、自摸在那一家面前打大字；胡和自摸带一圈金光；一炮多响打横幅。
- **结算卡**：每家胡了什么番型、几番、自摸 / 谁点炮，花猪 / 查叫状态，手牌缩略，本盘得失和累计；终局再加每盘得分表。
- **Mjai** 把对局拆成 start_kyoku / tsumo / dahai / pon / daiminkan / kakan / ankan / hora / ryukyoku 等事件，
  我们的行动 id 对应：`discard:5m`、`peng`、`gang`、`bugang:5m`、`angang:5m`、`hu` / `zimo`、流局在一盘结束时自动结算。

## 六、给模型的格式

五行：判断 / 推断 / 理由 / 胜率 / 最后一行行动，除行动外不超过 80 字。最后一行：
- 定缺：`定缺：条`
- 轮到自己：`出牌：5万`，或 `行动：自摸`、`行动：暗杠 5万`、`行动：补杠 5万`
- 响应：`行动：胡` / `行动：杠` / `行动：碰` / `行动：过`

提示词省 token：手牌按花色连写（`1123万 456条`），各家一行写定缺、张数、副露、牌河（已被拿走的不列），
直接列出可以打的牌和可选行动，附「听牌提示」（打哪张听什么、剩几张）。解析认全角冒号、「五万」「5m」「七条」「筒子」「不碰」等写法。

## 七、内置 AI

- level 1：随机合法（但能胡就胡、定缺挑张数最少的一门）——也是真人超时托管用的那一档。
- level 2：向听数（标准 4 面子 1 将 + 七对，按花色查表缓存）+ 进张数（外面还剩几张）选牌；牌形好时倾向清一色；
  碰杠只在能减少向听时要。
- level 3：level 2 再加防守：别家清完缺门、副露多、牌墙快完时视为威胁；他缺的那门、他打过的、外面没几张的牌更安全。
  血战里点炮只赔一家、自摸三家赔，弃胡收益小，所以防守权重偏轻。
