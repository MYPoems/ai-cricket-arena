# 掼蛋拆解（2026-11-24）

只看公开资料：机关单位、高校工会公开的掼蛋比赛规则（中国石油大学（北京）机关职工掼蛋比赛规则 PDF 等），英文维基 Guandan 条目，DanZero / DanZero+ 论文（arXiv 2210.17087、2312.02561），以及应用商店里掼蛋、记牌器类应用的公开说明。没有找到中国掼蛋协会规则原文；国家体育总局棋牌运动管理中心 2017 年发布过国标版《淮安掼蛋竞赛规则》，各地细则有出入，下面写的是多份公开规则的共同部分，有分歧处写明我们的取舍。商业产品只借交互思路，外观照本项目的漆面金边风格自绘。

## 一、规则要点

**人和牌**
- 4 人两队，对家是队友（本项目 1、3 号位一队，2、4 号位一队），出牌按座位顺序轮转。
- 两副牌 108 张（含 4 张王），每人 27 张。

**级牌与逢人配**
- 每盘有一个「级数」：两队都从 2 打起，每盘打上一盘头游那队的级。点数等于级数的牌叫级牌。
- 级牌在单张、对子、三张、三带二、炸弹里大于 A、小于小王；在顺子、三连对、钢板、同花顺里按原位置（例：打 7 时 5 6 7 8 9 仍是顺子）。
- 红桃级牌（两张）叫「逢人配」，可以当除大小王以外的任何牌；进贡时不能贡它。

**牌型**
| 牌型 | 构成 | 比较 |
|---|---|---|
| 单张、对子、三张 | 同点数 1/2/3 张；对子可以是一对小王或一对大王 | 牌力：2 < … < A < 级牌 < 小王 < 大王 |
| 三带二 | 三张 + 一对 | 只比三张 |
| 顺子 | 正好 5 张连续，A 可当 1（A2345 最小，10JQKA 最大），不能绕过 A | 比最小那张 |
| 三连对 | 3 个连续对子（AA2233 到 QQKKAA） | 同上 |
| 钢板 | 2 个连续三张（AAA222 到 KKKAAA） | 同上 |
| 炸弹 | 4 张及以上同点数，有逢人配最多可到 10 张 | 张数多的大，同张数比牌力 |
| 同花顺 | 同花色 5 张连续 | 比点数；大于 5 张以下炸弹、小于 6 张炸弹 |
| 四大天王 | 两小王 + 两大王 | 最大 |

炸弹类从小到大：4 张炸弹 < 5 张炸弹 < 同花顺 < 6 张 < 7 张 < … < 四大天王。炸弹类能压任何非炸弹牌型；非炸弹只能用同牌型更大的压。

**出牌**
- 领出可出任意牌型；后面的人压或不出（领出不能不出）。其余人都不出，最后出牌的人重新领出。
- **接风**：最后出牌的人已经出完，其余人都不出时，由他的队友领出。
- 张数报牌：剩 10 张以内必须报（比赛规则里漏报可被要求收回出牌）。

**名次与升级**
- 先出完的是头游，依次二游、三游、末游；头游那队赢这一盘。
- 头游队升级：队友二游（「双下」）升 3 级，三游升 2 级，末游升 1 级。打到 Q、K 时不能越过 A。
- **过 A**：打自己的 A 时，拿头游且队友不是末游，打过 A、赢下整场；多份规则写「三次打 A 不过退回 2」。

**进贡、还贡、抗贡**
- 从第二盘起，末游把除逢人配外最大的一张牌贡给头游；头游还一张点数不超过 10 的牌（全大于 10 时还最小的）；进贡的人先出。
- 头游与末游是同一队（1、4 名）时，同样是末游贡给头游。
- 双下：两个输家都进贡，大的给头游、小的给二游，贡大牌的人先出；两张一样大时按顺时针各贡给下家，头游的下家先出。
- 抗贡：进贡方（双下时两人合计）有两张大王就不进贡，头游先出。抗贡条件各地有分歧（一人两张 / 两人各一张），我们取「进贡方合计两张」。

**整场**：比赛规则通常限时（例：每轮 40 分钟），到时级数高的队赢，同级看谁先到；一方打过 A 立即结束。

## 二、流程

```
每盘：定级（上一盘头游队的级）→ 发牌（每人 27）
     → [第二盘起] 进贡（自动选最大牌）/ 抗贡 → 还贡（头游选牌）
     → 进贡者（或抗贡时头游）领出 → 轮流压牌、接风 → 名次 → 升级 / 过 A
整场：打满规定盘数或某队过 A → 级数高的队赢（同级看最后一盘头游）
```

## 三、成熟产品的交互与观战做法（公开资料里能看到的共同点）

- **理牌**：手牌按点数分列竖叠（同点数一列），大的在左；常见「一键理牌」把同花顺、炸弹单独排出来。级牌、逢人配有角标。
- **提示**：一个「提示」按钮依次给出能压过上家的出法（小的先、炸弹最后），只能「要不起」时自动过；选中的牌实时显示牌型。
- **逢人配**：选中的牌有多种组法时弹出选择（「作三带二 6」「作三带二 5」）。
- **出牌区**：每家面前留着本轮刚出的牌，桌心是要压的那一手；「不出」「接风」用气泡。
- **报牌**：剩 10 张以内名牌上亮红色张数。
- **记牌器**：两副牌每个点数还剩几张（不少独立记牌器应用专门支持掼蛋，说明这是刚需）。
- **进贡动画**：一盘开始时列出谁贡给谁、还了什么，贡牌亮出、还牌只给双方看。
- **结算**：每盘结束弹名次、升几级、两队当前级数；整场结束弹终局。

**AI 方面**：DanZero 论文说明掼蛋合法动作空间约 10⁴、全部动作约 10⁶（逢人配让组合爆炸），他们用 54 维计数向量编码出牌，强化学习训练 30 天；对照用的是首届中国掼蛋 AI 大赛前 8 名的规则型机器人。可借鉴的结论：不能把全部合法出法列给模型，要给精简候选 + 接受任意合法写法。

## 四、我们的实现

**完整实现**：两副牌发牌（带种子可重现）、级牌与逢人配、全部牌型（含 A 当 1、最多 10 张的炸弹、同花顺、四大天王）、炸弹类大小顺序、接风、头游到末游、双下 / 1·3 / 1·4 升级、不能越过 A、过 A 条件、打 A 三次不过退回 2、单贡 / 双贡 / 同大顺时针 / 抗贡、进贡者先出。

**给模型**
- 提示词：手牌按牌力紧凑分组（`A♠♦♦` 表示三张 A），写明级牌和逢人配、两队级数、本盘第几盘、队友是谁、各家剩余张数（≤10 标报牌）、本轮要压的牌和牌型、最近 3 轮出牌、别家还可能有的大牌（王、级牌、逢人配、A 的剩余张数），最后一行「出牌：…」。
- 行动列表只给精简候选（按提示顺序，领出每种牌型最多几个、跟牌最多 24 个 + 炸弹 8 个 + 不出）；`apply`、`parseReply` 接受任何合法写法：只写点数、写花色（黑桃 / ♠ / S）、写「逢人配」「配」；只写点数的 5 张会额外试凑同花顺。2026-11-25 挑刺后又放宽：markdown 加粗（`**出牌：**`）、「对3」「一对小王」「三个5」「五张8」、照抄手牌写法（「5♠ 5♣」「A♠♦」「小王×2」「逢人配♥7」）、「级牌7」、「1」当 A、「T」当 10、照抄记录里的「三带二 6 6 6 5 5（♥7当6）」。
- 逢人配有几种组法时：写了「♥7当5」（括号里也认）就按它；只写点数、某个点数不够由逢人配补（手里两张 5 写「5 5 5 6 6」）就当那个点数；都没有时跟牌取能压过上家的最小组法，领出取最强组法（例：领出「♥7 5 5 6 6」认作三带二 6）。行动 id 带组法（`♠5 ♣5 ♦5 ♠8 ♥7=fullhouse:5`），真人在界面上选了哪种就按哪种。
- 「不出」的 id 是 `pass`（真人超时默认它）；还贡写「还贡：♣5」（例子换成本人真能还的牌，写错时错误信息列出能还的牌）。
- 要不起（手里没有任何能压过上家的牌，含炸弹）时 `autoAction` 直接「不出」，不问模型也不等真人：自对弈里约 36% 的步是这种，省下的调用很可观。

**内置 AI**
- level 1：在候选里随机。
- level 2：估算「剩下的牌还要几手出完」（炸弹不拆、钢板 / 三连对 / 顺子搜索、三张带对子），选让手数最少、用牌最小的一手；少用逢人配和级牌；队友出的牌不压；对手剩 6 张以内才动炸弹；对手报单 / 报双时领出避开那个张数。
- level 3：再加记牌（两副牌减去自己的和出过的，判断一手牌别人还管不管得住）和残局（剩两手、其中一手管不住时先出它；队友只剩一两张时领小牌送他；对手快走完时队友的小牌也接）。
- 自对弈：level 2 对 level 1 胜率 100%（60 场）；level 3 对 level 2 约 51%（1200 盘），残局规则带来的提升很小。

**画面**：深红漆面 + 金边牌桌，对家坐对面；自己的手牌同点数竖叠、级牌标「级」、逢人配标「配」；桌心是要压的一手（逢人配标出当的点数），各家面前留本轮出过的牌，「不出」「接风」气泡；名牌上剩余张数，≤10 张亮「报 N」；左上牌匾写第几盘、打几、两队级数（打 A 时标第几次）；右上记牌器；一盘开始时进贡还贡面板（还的牌只有双方看得见，抗贡另写），一盘最后一手出完先在桌心停 1.5 秒（标「最后一手」），再升起结算卡：升几级和原因（「1·3 队头游 + 队友二游（双下）：升 3 级 2 → 5 · 下一盘打 5」，升到 A 为止、打 A 未过、退回 2 都写）、最后一手（小牌）、名次和剩余张数；服务端一盘结束停 5.6 秒。整场结束终局卡（可收起成小签；对局页自己的终局卡浮着时先藏起，免得两张叠在一起）。桌心、进贡面板里的人名前都带座位号圆片（几个座位都是同一个内置 AI 时分得清）。真人：点选 / 横划选牌，「不出」「提示」「重选」「出牌」，逢人配多种组法时在按钮上方选一种；还贡时只能点能还的牌；交出去后到新局面之前按钮变灰，防连点重复提交。手牌列多时左右压住一部分（每列露出六成，点数和「级」「配」角标都在露出的部分），牌更大，手机竖屏尤其明显。领出时「提示」先给不用逢人配、不拆牌的出法。

## 五、简化和取舍（理由）

| 取舍 | 理由 |
|---|---|
| 不限时，按盘数（默认 3 盘，1–13）结束；同级按最后一盘头游 | 大模型对局一盘要几十分钟，按时间结束不可控 |
| 进贡自动选（除逢人配外最大的一张，同点数随便哪个花色） | 规则规定必须贡最大的，花色几乎不影响局面，省一轮模型调用 |
| 还贡是真人 / 模型的决策（私密行动） | 还什么牌真影响牌力，是值得看的思考 |
| 抗贡取「进贡方合计两张大王」 | 多数公开规则的写法 |
| 双贡同大时各贡给下家、头游的下家先出 | 「顺时针、贡左还右」的一种确定写法 |
| 第一盘随机定首出（种子决定），不做翻明牌、抓牌 | 发牌一次完成，翻牌只是定首出的仪式 |
| 不做报牌违规（漏报收回） | 张数由系统实时显示，不存在漏报 |
| 双下时三游、末游不再区分（按剩余张数排） | 两人都进贡，名次只影响显示 |
| 不做「一键理牌」成同花顺 | 只按点数竖叠；同花顺由「提示」给出 |
| 1、4 名时末游贡给自己队的头游 | 公开规则如此，保留 |

## 六、已知问题

- level 3 比 level 2 只强一点；更强需要模拟对手手牌（采样 + 推演），超出内置 AI 的时间预算。
- 进贡还贡在有真人的对局里是私密步（`secret`），观众进行中看不到还贡这一步；本盘记录的行数和步号在这时会差一两步。
