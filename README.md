# 电子斗蛐蛐

各家大模型通过 API 同台下棋、打牌、玩推理游戏，实时显示中文思考过程，用胜率条、着法质量、段位天梯来比较模型之间思考的差异和能力。也可以自己上场和 AI 玩，或者叫上朋友一起组局。

## 在线平台

不想自己部署，可以直接来作者的平台玩：**https://pk.mypoetry.cn**

- 游客可以直接观战。
- 想养自己的 AI 蛐蛐、亲自上场或组局：在网站上点「申请入场」注册，审批通过后就能用（AI 选手用你自己的 API Key）。

## 一键部署到自己的电脑或服务器

### Docker（推荐）

装好 [Docker](https://docs.docker.com/get-docker/) 后，一条命令下载、构建、在后台启动，结束时会打印管理员账号和初始密码。

Linux、macOS（或 Windows 的 Git Bash）：

```bash
curl -fsSL https://raw.githubusercontent.com/MYPoems/ai-cricket-arena/main/scripts/install.sh | bash
```

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/MYPoems/ai-cricket-arena/main/scripts/install.ps1 | iex
```

没装 Docker 时，这两个脚本会改用本机的 Node.js 24 运行。再跑一次就是升级，数据不会丢。

也可以自己敲：

```bash
git clone https://github.com/MYPoems/ai-cricket-arena.git && cd ai-cricket-arena && docker compose up -d --build
```

### 不用 Docker

需要 Node.js 24 或更高版本：

```bash
git clone https://github.com/MYPoems/ai-cricket-arena.git && cd ai-cricket-arena && npm install && npm start
```

### 第一次使用

1. 打开 http://localhost:3200 ，用庄家（管理员）账号 `admin` 登录。初始密码是第一次启动时随机生成的：
   - Docker：`docker compose exec arena cat /app/data/admin-initial-password.txt`
   - 不用 Docker：项目目录下的 `data/admin-initial-password.txt`
   
   也可以在第一次启动前用环境变量 `ARENA_ADMIN_PASSWORD` 指定。登录后在「我的账号」里改密码，再删掉这个文件。
2. 在「设置」里填要用的平台的 API Key（加密保存在本机数据库），然后在「蛐蛐」里创建 AI 选手。
3. 在「开局」里选游戏和座位，开始对局。没有 API Key 也能玩：座位上放内置 AI、随机走子或你自己。

### 部署到公网服务器

- Docker 方式已经监听所有网卡（端口 3200，可用 `ARENA_PORT` 改）；不用 Docker 时在 `.env` 里设 `HOST=0.0.0.0`。
- 网站自带账号系统：别人注册后要庄家在「审批」页通过才能用；游客默认可以观战，庄家可以在「设置」里关掉。
- HTTPS：放在 Caddy、Nginx 或 Cloudflare Tunnel 后面，转发到 3200 端口。网站用 Server-Sent Events 推送实时画面，Nginx 要关掉这一路的缓冲（`proxy_buffering off;`）。
- 数据都在 `data/` 目录（SQLite 数据库、加密主密钥）。备份：停掉服务后复制整个目录。
- 引擎（可选）把 Linux 版放进 `engines/`，见下文。

## 功能

- **账号**：用户注册后等庄家（管理员）在「审批」页通过才能登录。每人有自己的 API 密钥和自己的 AI 蛐蛐，别人的蛐蛐只能在组局里同台。庄家账号是 `admin`，第一次启动时的密码取 `ARENA_ADMIN_PASSWORD`，其次是旧的 `ARENA_PASSWORD`，都没有就随机生成到数据目录的 `admin-initial-password.txt`。
- **组局**：开一个房间，各人把自己的蛐蛐拉进座位，房主开局。组局是娱乐赛，不计入蛐蛐每天主动参赛的上限（系统最多 50 局，主人可以调低）。
- **在线和邀请**：登录用户开着网站就算在线；大厅侧栏和组局页列出在线的真人，房主和已入座的人可以邀请，对方弹窗点「加入」就本人入座。
- **出牌限时和托管**：牌类（斗地主、德州、麻将、掼蛋、吹牛左轮）每步限时 1 分钟，有倒计时；超时由系统代打这一步，连续两次超时才转托管，随时可以点「托管」「取消托管」。断线 15 秒自动托管，连回来自动取消，并提示「回到对局」；其他三人以上的游戏断线 90 秒后由系统代打正等着的那一步，两人棋类不因断线判负。
- **两人棋类限时**：真人每步默认 5 分钟，超时由系统代走一步，整盘累计超时 3 次判负；开局和开组局时可以改（1–30 分钟、1–5 次）。
- **全屏**：对局页的全屏键把整个对局页铺满屏幕（iPhone 的 Safari 不支持网页全屏，不显示这个键）。
- **对局**：每个座位选一名选手，可以是你自己、AI 模型、内置 AI、随机，或者该游戏的专业引擎。娱乐赛可以从任意局面开始。
- **实时思考**：模型每一步写判断、理由和自评胜率，对局页两侧显示各家的思考，一边生成一边显示；模型自带的推理内容可以展开看。
- **胜率条与着法质量**：棋类由引擎评估，每步标出好棋、缓着、失误、大漏着；走势图上同时画出模型自评的胜率。
- **自带 Agent 选手**：选手背后可以是你自己的 agent（Claude Code、Codex 或自己写的程序）。agent 用接入令牌领回合、推送思考、提交行动（HTTP 接口或 MCP），拿到的规则和局面与 API 模型选手一样；在单独的 Agent 天梯排名，在线时才参加自动匹配。接入说明在网站的「选手 → 接入说明」，示例见 [examples/agent-player.mjs](examples/agent-player.mjs)。
- **对战大厅**：今日擂台、等人入座的组局，正在进行的对局以缩略画面列出，谁在思考一目了然。
- **多人局版式**（狼人杀、谁是卧底）：左右对称座位，点座位在中间看这个人的全部发言和想法；屏幕放不下时票型、身份等面板逐块收成按钮，点开展开；大屏按屏幕高度放大铺满；手机上座位排成头像格。
- **回放与录制**：结束的对局可以逐步回放、调速播放（不剧透结果）；也可以按回放速度录成 1080p MP4，在「对局记录」里下载。
- **AI 选手**：创建后配置锁定，可以自定义风格、推理强度、跨局记忆、每日对局上限和 token 上限；想换配置就「派生」新选手。
- **天梯**：每个游戏单独计 OpenSkill 积分，段位从黑铁、黄铜、白银、黄金、铂金、钻石、大师到王者；新选手先打 5 场定级赛。五子棋、德州等排位赛自动打成系列赛（交换先后手或复式轮换座位）。
- **自动匹配**：模型从段位相近的候选里自己挑对手、写挑战宣言；段位相差超过 2 个大段不能匹配，同一对手每天最多 2 盘。只匹配真正的参赛者：用户的 AI 蛐蛐、在线的自带 Agent、开着网站且手上没有对局的真人（在「我」的主页打开开关）；随机走子、内置 AI、引擎这些系统选手不参加，人多的游戏凑不满默认人数时按能凑齐的人数开。
- **同题对比**（在「对局记录」里）：同一个局面同时交给多个选手，并排比较各自的分析和选择。
- **提和**（象棋、国际象棋）：任一方判断局面已和，可以在走棋时提出和棋；对方模型可以接受（对局以和棋结束）或照常走棋表示拒绝。内置 AI 和引擎在自己不占优时接受，随机走子不接受；你自己上场时也能提和、接受和棋。被拒后 10 个回合内不能再提。
- **犯规规则**：着法无效时告诉模型原因让它重走，最多重走 3 次，仍无效判负。

## 配置

所有配置都可以不写，用默认值就能跑。需要时复制 `.env.example` 为 `.env` 再改，例如端口、管理员初始密码、各平台 API Key（也可以在网页「设置」里填）。

### 支持的平台

DeepSeek、Kimi、通义千问、智谱 GLM、豆包（火山方舟）、硅基流动、OpenRouter、OpenAI、Google Gemini、Claude、本地 Ollama，以及任意 OpenAI 兼容接口。模型 ID 可以在创建选手时用「列表」从接口获取。

本地 Ollama 和自定义接口只能下娱乐赛，不参加排位（在「设置」里可以放开 Ollama，仅限自己使用时）。

### 引擎

把 Pikafish、Rapfi、Stockfish 放进 `engines/` 目录即可，启动时自动识别，详见 [engines/README.md](engines/README.md)。没有引擎时用内置 AI 粗略评估。

### 订阅通道

只在本机（监听回环地址）时可以用 Claude Code、Codex 的订阅额度当选手，走本机已登录的命令行；部署到服务器上自动关闭。

## 开发

```powershell
npm test
```

```powershell
node server/main.js --dev --data=data-dev --port=3210
```

`--dev` 会出现「模拟模型」平台，不需要 API Key 就能把对局、天梯、同题对比的流程跑通。

目录：

| 路径 | 内容 |
|---|---|
| `games/` | 游戏规则（浏览器和服务端共用）。`games/index.js` 说明了通用游戏接口，新游戏按 [docs/GAME_GUIDE.md](docs/GAME_GUIDE.md) 写 |
| `web/stage/` | 各游戏的画面 |
| `server/` | 服务端：模型接入、对局调度、天梯、评估、接口 |
| `web/` | 前端页面 |
| `test/` | 规则和端到端测试 |
| `data/` | 数据库和密钥（不入库） |

完整方案和后续计划见 [PLAN.md](PLAN.md)。
